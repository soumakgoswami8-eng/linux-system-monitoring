# linux-system-monitoring
# Linux System Monitoring Dashboard

A menu-driven Linux system monitoring utility developed using Bash Shell Scripting.

## Features

- System Information
- CPU Usage
- Memory Usage
- Disk Usage
- Logged-in Users
- System Uptime
- Network Information
- Top CPU Processes
- Top Memory Processes
- Process Search
- System Report Generation
- Action Logging
- Input Validation
- Ctrl+C Handling

---

## Technologies Used

- Bash Shell
- Linux Commands
  - top
  - ps
  - free
  - df
  - who
  - uptime
  - ip
  - grep
  - awk
